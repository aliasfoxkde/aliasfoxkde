What “dynamic” means here

The editor dynamically builds the SVG in your browser and exports a self-contained image. GitHub profile READMEs do not execute page JavaScript. These downloads are static; if you want live counts, connect the template to a scheduled workflow or your own API endpoint. Test the final SVG in your target README because host sanitization and animation support vary.
